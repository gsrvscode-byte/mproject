PROJECT 1
---------
Title: Insurance Management Platform — Health, Travel, Motor & Two-Wheeler
Duration: May 2024 – Present
Tech Stack: Node.js, Express.js, MongoDB, MySQL, REST, XML, SOAP, Redis, Docker

Description:
Built and maintain backend workflows for an insurance platform covering
Health, Travel, Motor and Two-Wheeler products. Developed APIs for
quotation, proposal processing, portability, EMI and policy management.
Implemented insurer-specific business rules for age-based eligibility,
relationship validation, medical declarations and hospitalization
checks. Integrated multiple external insurer and ERP systems through
REST, XML and SOAP interfaces with structured request/response
handling and error management. Optimized MongoDB using aggregation
pipelines, indexing and query filtering to improve proposal and
reporting performance.


PROJECT 2
---------
Title: AI-Powered Policy PDF Parser
Duration: 2024 – Present
Tech Stack: Node.js, OpenAI API, Python, FastAPI, Formidable, Docker, JSON

Description:
Designed and built an AI-powered document processing service that
automatically extracts structured data from insurance policy PDFs.
Developed Node.js APIs for multipart PDF upload and orchestration, and
designed extraction schemas and prompts for Health, Motor and
Two-Wheeler policy documents using the OpenAI API. Extracted structured
customer, policy, vehicle, coverage, nominee, discount and partner
information into clean JSON. Connected the Node.js layer to a
Python/FastAPI microservice for AI processing, using structured JSON
communication between services.


PROJECT 3
---------
Title: Transport ERP Web Application
Duration: 2022 – 2024
Tech Stack: Node.js, Express.js, React.js, HTML5, CSS3, REST APIs, Redis, Docker, AWS

Description:
Developed a Transport ERP application for managing and coordinating
material movement and transportation workflows. Built backend REST

INDEED PROFILE TIPS (Indeed-specific, in addition to Naukri tips)
--------------------------------------------------------------------
- Indeed's "Resume" and "Work Experience" sections are searched by
  recruiters using exact keyword match, same as Naukri — make sure
  Node.js, React.js, MongoDB, Docker, AWS, REST API, JWT, Redis,
  RabbitMQ all appear as plain text somewhere in your profile, not
  just inside a skills widget.
- Fill "Job Title" on Indeed exactly as "Node.js Full Stack Developer"
  or "Node.js Developer" — Indeed's search matches job title text
  heavily.
- Turn on "Open to work" / visibility to employers in Indeed settings.
- Upload the same resume file you use elsewhere (consistency helps
  when a recruiter cross-checks LinkedIn/Naukri/Indeed).
- Set expected salary range on Indeed — profiles with salary filled in
  get shown in more recruiter searches than blank ones.
- Answer Indeed's optional "assessment" tests (Node.js, JavaScript,
  SQL) if prompted — a passed assessment badge on your profile
  increases recruiter click-through significantly.
